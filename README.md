# POWER_BI-AMAZON-SALES-REPORT
A sales dashboard built using powerbi to analyze regional performance
This project is a Power BI dashboard analyzing sales performance across regions and products.
## Tools Used
- Power BI Desktop
- google colab(for data cleaning using python libraries)
- Excel (for data cleaning)

## Features
- donut charts for better understanding
- Regional sales 
- regional trends
- slicer for better and fast access
